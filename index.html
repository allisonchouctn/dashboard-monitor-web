1. 系統總覽與效益

本系統旨在建立自動化數據品質防護機制，有效解決過往資料更新中斷、欄位遺失或數據異常未即時發現之問題。

  • 自動化排程派送：透過 GitHub Actions 於每日指定時間自動喚醒執行，完成數據品質檢驗與 HTML 報告派送。
  • 高彈性設定檔架構：僅需於 MONITOR_CONFIG 工作表中填寫目標報表名稱、date_column 及指定檢驗欄位，即可完成監控設定。
  • 基準日期自動檢驗：以系統當前日期為基準，自動執行資料完整性檢核（含欄位存在性、D-1 更新狀態、7日日期連續性、每日筆數波動及指標異常檢測）。
  • 視覺化健康度通報：系統依據檢測結果（PASS/FAIL）自動切換郵件主題視覺，精準標示異常項目與原因。

2. 新增檢查報表與運作流程

若需新增 Google Sheet 監控項目，無須更動任何程式碼，僅需完成以下設定流程：

📖 Step 1. 編輯 Monitor 設定檔

請至監控主表之 Monitor - MONITOR_CONFIG 工作表中新增列位（如需減少監控表單，直接於設定檔中刪除對應列位即可）：

欄位名稱 說明 範例
spreadsheet_name 目標 Google Sheet 之檔案名稱 Spreadsheet_Name
worksheet_name 欲監控之特定工作表（分頁）名稱 Worksheet_Name
date_column 資料表中作為日期基準之欄位名稱 Date_Column
metrics 欲執行數據比對之數值欄位（多個請以逗號隔開） Data_A, Data_B, Data_C

3. 數據檢驗報告呈現

檢測結果將自動整理並渲染為結構化之電子郵件報告：

📄 報表基礎檢驗摘要

檢驗項目 檢測現況 / 明細 狀態
目標報表名稱 Spreadsheet_Name -
監控工作表 Worksheet_Name -
整體健康狀態 D-1 資料完成更新，數據檢驗正常 / 數據缺失或筆數異常，觸發警報 🟢 PASS / 🔴 FAIL
最新更新日期 D-1 (YYYY-MM-DD) | D-2 (YYYY-MM-DD) -
資料筆數變動 D-1: Number 筆 | D-2: Number 筆 (+/-%) -

📊 多維度數據比對明細

比對維度 檢驗目的 D-1 / 當期數值 對照期數值 變動幅度 (%)
[D-1 vs D-2] 檢測單日突發性數據異常 Number Number (D-2) +/-%
[D-1 vs 7日均] 評估偏離近週平均之程度 Number Number (7日均值) +/-%
[MTD 比對 (MoM)] 追蹤當月累計成長趨勢 Number (本月) Number (上月同期) +/-%
[YTD 比對 (YoY)] 評估跨年度累計數據合理性 Number (今年) Number (去年同期) +/-%
💡 多維度比對機制說明：
  • D-1 vs D-2：第一時間識別資料數值是否維持正常更新。
  • D-1 vs 7日均值：識別資料數值是否異常爆量/減少，並過濾週期性（如週末）波動，降低誤報機率。
  • MTD / YTD 比對：從長期角度檢視月度與年度累計數據之連續性。
